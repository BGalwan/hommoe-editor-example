# hommoe-editor-example

**Welcome!** This repository serves as a comprehensive, community-maintained collection of modular, bite-sized sample maps and campaign templates designed to demonstrate the full spectrum of capabilities of the **Heroes of Might and Magic: Olden Era** (HOMM Olden Era) Map & Campaign Editor.

## 🔍 Overview

Whether you are building your first 1v1 skirmish map or orchestrating a multi-chapter custom story campaign, the *HOMM: Olden Era Editor* provides rich visual scripting, heightmap sculpting, variable tracking, and campaign branching tools.

Instead of hunting through complex full-length maps, this repository provides **focused, isolated examples** for every key feature. Each map is engineered to demonstrate **one primary mechanic** cleanly, with full internal annotations, visual trigger node diagrams, and documented script logic.
