# hommoe-editor-example

**Welcome!** This repository serves as a comprehensive, community-maintained collection of simple sample maps to demonstrate the capabilities of the **Heroes of Might and Magic: Olden Era** (HOMM Olden Era) Map & Campaign Editor.

## 🔍 Overview

Instead of hunting through complex full-length maps, this repository provides **focused, isolated examples** for every key feature. Each map is engineered to demonstrate **one primary mechanic** cleanly, with simple annotations and documented logic.
